# GeoCart

GeoCart is an iPhone shopping-list app that reminds you when you arrive near a saved store. Lists and saved locations remain on the device, while Apple region monitoring keeps reminders battery-friendly.

- Location-based shopping reminders
- Saved stores and reusable lists
- Local-first design with no advertising trackers
- Built for iPhone

[Visit the GeoCart website](https://geocart.unlertu.workers.dev/)

## Source availability

This repository is a product showcase. The application and website source code are private.
